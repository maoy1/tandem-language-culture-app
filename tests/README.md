# Tests

Place automated tests here. Tests should use synthetic data and should not
require real employee records or secrets.

See [the test catalogue](../docs/TEST_CATALOGUE.md) for stable scenario IDs,
fixtures and expected results across repository checks and deployed app/flow tests.
Record actual executions and remaining gaps in
[test run records](../docs/TEST_RUNS.md). Planned scenarios are not implemented
automated tests and are not evidence of a passing deployment.

For a bug report, include the test ID if known, steps, expected/actual behavior,
app/flow version and sanitized evidence. Reporting in ordinary language is also
fine; the relevant regression case can be identified or added during investigation.
