Outputs: success/replay/writeattempted/outcomeunknown Boolean; resultcode/message/resultjson/runreference/buildid/mode Text. Success only LEFT after completed receipt proof and old-token absence. `resultjson` contains kind/operationkey/groupid/membershipid/status=Left/leftat/groupstate/membercount/freeslots; no account/email/raw membership/group rows or attempt token. Failure returns `{}`. Count includes **all physical Active rows**, including provisional/paused members, read bounded/complete under group ownership. Free slots=max(0,Capacity-count). Replayed counts/state are the historical saved result; refresh for current counts/state.

OperationKey `leave:ACTOR:lowercase-UUID`; IntentJson frozen typed equality includes kind/version/actor/group/episode. `Groups.WriteOwner = OperationKey + ':' + server attempt UUID`, <=255 chars. This matches #11's opaque operation:attempt string and same empty-field exact-ETag mutex. Cross-writers share only WriteOwner on the group; Leave never patches State/Capacity/focus/setup. It neither interprets nor clears another token. #11 currently uses a run reference for its attempt suffix; the mutex is compatible because tokens are opaque, and Leave uses the requested UUID suffix. Parent must keep cross-writer format/255-bound enforcement aligned before cutover.

Commit authorization is separate from physical counting. Group.SetupComplete and its SourceRequestId's Accepted+OperationComplete Personal request must hold. MembershipKey is parsed as canonical `request:ID:participant:ACTOR`; that exact request must be Accepted+OperationComplete. Initial personal episode must use the group source and include actor as sender/recipient. Joined episode must use a Group request targeting this group and actor as sender/null recipient.
